## How it works

`main.py` (Python standard library only) holds the joke as a single string,
checks the bounty gate — exactly one line, non-blank, 1–200 characters —
then writes it to `/output/entry.txt` with no trailing newline and re-reads
the file to confirm the contents match exactly.
